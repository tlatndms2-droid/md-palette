# MD Palette — UI Reference Policy

## 목적
UI Reference 이미지는 분위기 참고가 아니라 **구현 기준 자료**다.

Codex는 가능한 한 다음을 이미지와 유사하게 구현해야 한다:
- 화면 구조
- 레이아웃
- 상대적 크기 비율
- 여백/간격
- 컨트롤 위치
- 정보 밀도
- 시각적 계층
- Obsidian 다크 UI와의 조화

## 충돌 처리
### 문서와 이미지가 충돌
Codex는 임의로 어느 한쪽을 우선하지 않는다.
반드시 사용자에게 직접 확인한 뒤 진행한다.

예:
- 이미지에는 버튼이 있으나 문서에는 없음
- 문서에는 기능이 있으나 이미지에는 없음
- 위치/용어/상태/동작 결과가 다름
- 어느 쪽이 최신인지 불명확

사용자 확인 전 해당 UI 영역을 확정 구현하지 않는다.

### 문서에는 없고 이미지에 순수 시각 세부만 있음
UI Reference를 따른다.

### 이미지에 문서에 없는 새 기능/동작이 보임
임의 구현 금지.
사용자에게 확인.

## 우선순위
1. 사용자 최신 확정 답변
2. 최신 Markdown 기획 문서
3. UI Reference 이미지
4. 충돌/애매함 → 사용자 확인
