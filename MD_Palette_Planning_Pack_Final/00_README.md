## 핵심 해석 규칙
- 사용자 최신 확정 답변이 최우선.
- 문서와 UI Reference가 충돌하면 Codex가 임의 해석하지 않고 사용자에게 직접 확인.
- 문서에 없는 순수 시각 세부는 UI Reference를 참고.
- 이미지에 문서에 없는 기능/버튼/동작이 보이면 구현 전에 사용자 확인.
- API 선택, 클래스/함수/파일 구조, 알고리즘, 최적화 방식은 Codex 영역.
