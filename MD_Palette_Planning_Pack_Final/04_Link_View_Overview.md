# MD Palette — Link View Overview

## 구조
- Card View
- Connections View
- Folder View

항상 현재 Main 기준.

## 공통 파일 유형 Filter
- 전체
- Markdown
- Canvas
- PDF
- Image
- Video
- Other

Card와 Folder 공유, 재시작 후 복원.
Connections는 Markdown-only.

## 연결 파일 추가
### Card / Connections
상단 `연결 파일 추가`

### Folder
현재 Folder Section 빈 공간 우클릭 → `연결 파일 추가`

공통:
1. 기존 Vault 파일 선택
2. Main `link note`에 링크 추가
3. Outgoing Link 생성
4. View 자동 갱신

Backlink를 직접 생성하는 기능은 없음.

## Folder에서 연결 파일 추가
- Main `link note` Outgoing 생성
- 현재 Virtual Folder 배치
- 둘 다 성공해야 완료
- 일부만 성공한 상태를 최종 결과로 남기지 않음

이미 다른 Virtual Folder에 배치된 파일:
- 연결 추가 안 함
- Virtual 위치 변경 안 함
- 전체 작업 취소
- Notice: `이미 다른 가상 폴더에 배치된 파일입니다.`
