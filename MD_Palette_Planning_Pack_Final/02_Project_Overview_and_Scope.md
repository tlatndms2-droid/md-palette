# MD Palette — Project Overview & Scope

## 한 문장 정의
MD Palette는 Obsidian의 기존 Workspace/Editor를 유지하면서 Main Markdown을 중심으로 연결 Note, 참고 자료, 연결 파일, 문서 내부 요소를 탐색·정리·재사용하는 Desktop Obsidian Plugin이다.

## 핵심 사용자 흐름
1. Markdown 활성 Tab에서 `메인 스페이스로 지정`
2. Main 기준으로 연결 Note 생성 또는 기존 Vault 파일 연결
3. Markdown 연결 파일은 Sub, 참고 자료는 Reference에서 사용
4. Link View에서 Card / Connections / Folder 방식으로 탐색
5. Metadata View에서 각주 / Highlight / Task / Block Reference 탐색
6. Drag & Drop으로 Main/Sub/Reference/Canvas에 재사용

## 포함
- Desktop Obsidian
- Main/Sub/Reference Space
- Link View
- Metadata View
- Virtual Folder
- Label
- 재시작 시 역할/상태 복원
- UI Reference 기반 구현

## 제외
- Mobile 대응
- MD Palette 작업 데이터 전체 초기화 기능
- 독자 Markdown Editor
- 실제 Vault Folder 대체/재구성
- 자동 parent/child hierarchy
- Codex의 내부 구현 구조 확정
