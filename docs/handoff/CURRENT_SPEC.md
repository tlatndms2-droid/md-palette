# 현재 확정 사양 — MD Palette 0.0.15

작성 기준: 2026-09-21, 코드 `9761cff`, 배포 기록 `fbd11ad`. 이 문서는 새 기능 제안이 아니라 기존 사용자 결정과 구현 상태의 정리다. 세부 근거는 [변경 이력](DECISIONS.md), 사용자 사용법은 [README](../../README.md)를 함께 읽는다.

## 1. 프로젝트의 목적과 화면

Obsidian에서 Main 노트를 기준으로 연결된 자료를 보고 정리하고, Sub에서 자료를 열거나 내용을 재사용하는 데스크톱 플러그인이다. 독자 편집기를 만들지 않는다.

- 사이드바: Link View / Metadata View.
- Link View: Card / Connections / Folder.
- 기본 Obsidian 탭 그룹에 Main·Sub 역할을 부여한다. Reference 역할과 Main/Sub 교환은 없다.
- 색상은 Obsidian 테마와 강조색, 배치·간격·밀도는 제공 참조를 따른다. 과거 이미지의 폐기된 기능을 복원하지 않는다.

## 2. Main과 Sub

- 중앙 작업 영역의 지정 가능한 Markdown 탭 우클릭으로 Main을 지정한다. Sub에서는 Main을 지정하지 않는다.
- Main은 지정한 문서와 탭에 고정된다. 같은 그룹의 다른 탭을 본다는 이유로 기준 문서를 바꾸지 않는다.
- Main 탭을 닫거나 다른 파일로 교체하면 지정을 해제한다. 재시작 때 사라진 Main을 새로 열지 않는다.
- `메인 스페이스 지정/해제` 명령: 같은 Main에서는 해제, 다른 지정 가능한 Markdown에서는 새 Main 지정. 기존 지정 명령 단축키를 유지한다.
- Main 변경·해제: 기존 Main/Sub와 일반 탭은 닫지 않는다. 이전 역할과 아이콘을 해제한다. 이전 Sub를 새 Main에 자동 연결하지 않는다.
- 카드·파일 한 번 클릭은 선택이다. Ctrl/Shift 선택만으로 파일을 열지 않는다.
- 기본 더블클릭: 마지막 사용 Sub 그룹의 현재 탭을 교체한다. 다른 비활성 탭은 보존한다.
- Ctrl+더블클릭: 같은 Sub 그룹에 새 탭. Ctrl+Shift+더블클릭: 새 Sub 그룹.
- 대상 Sub 그룹에 같은 파일이 있으면 기존 탭을 사용한다. 새 그룹 추가는 같은 파일도 허용한다. 전체 그룹을 통틀어 무조건 하나로 제한하는 방식이 아니다.
- Markdown·이미지·Canvas·PDF·영상 등 지원 파일을 Sub에서 연다. Main 본문·속성의 내부 링크도 Sub로 열고 일반 문서의 링크 동작은 유지한다.
- Main 위에 영상이 있다면 영상과 Main의 위아래 관계를 왼쪽에 유지하고, Sub는 오른쪽 전체 높이를 쓴다. 기존 아래쪽 Sub도 재배치한다. 여러 Sub와 마지막 사용 그룹을 저장·복원한다.
- Main 본문 링크의 별도 선택 팝업은 보류다. Metadata 웹 링크 메뉴와 혼동하지 않는다.

## 3. 연결·Card·라벨

- Main의 나가는 링크와 역링크를 모은다. Card/Folder에서는 같은 파일을 한 번 표시하며 Main 자신은 숨긴다.
- `연결 파일 추가`: 기존 파일 선택 → Main의 `link note` 속성에 연결. 본문에 별도 링크 목록을 만들지 않는다.
- Card: 썸네일·파일 유형 필터·라벨 필터·보기 형식·텍스트 크기·다중 선택·순서 변경. 드래그 안내선과 선택 묶음의 상대 순서를 유지한다.
- Card/Folder 파일 제목은 위쪽에 크게 표시한다. Markdown 미리보기는 제목·강조·목록·링크를 렌더링하고 본문 임베드는 링크로 표시한다.
- 라벨은 파일당 하나. 선택 파일에 일괄 적용·제거 가능. 전체 Vault에서 라벨별 파일 수·파일 목록·라벨 삭제를 제공한다. 라벨 삭제는 파일 삭제가 아니다.
- Ctrl 미리보기: Card 파일, Folder 파일 카드/Tree 파일, Connections 파일 행. 버튼·가상 폴더·Metadata로 확대하지 않는다.

## 4. Connections

- Markdown 파일의 Backlinks·Outgoing 및 Obsidian 기본 Local Graph를 표시한다.
- Outgoing은 본문과 모든 속성의 Markdown 연결을 포함한다. `link note`만 읽는 것으로 되돌리지 않는다.
- 그래프는 Obsidian 기본 View·설정 UI를 재사용하며 Main 중심으로 보여준다. 자체 SVG 그래프로 바꾸지 않는다.
- 영역 접기·높이·저장·재시작 복원. 별도의 목록 검색창·필터는 제외했다.

## 5. Folder와 저장

- 가상 폴더·파일 배치·보기·정렬·접힘·분할은 **Main 문서 경로별** 플러그인 데이터다.
- 같은 자료가 Main A와 B에 연결되면 각 Main에서 서로 다른 가상 폴더에 둘 수 있다. 한 Main 안에서는 파일당 가상 위치 하나다.
- 복합뷰(Tree+Folder) / Tree뷰 / Folder뷰, 생성·이름 변경·이동·삭제, 단일·다중 드래그, 순환 이동 금지, Esc 취소를 지원한다.
- 폴더 삭제는 바로 안의 파일·하위 폴더를 한 단계 위로 옮긴다. 실제 Vault 파일은 이동·삭제하지 않는다.
- 뒤로·앞으로·위로·경로 이동. 검색은 현재 폴더와 하위 폴더 전체이며 Main 변경·재시작 때 비운다.
- Folder 정렬: 사용자 지정·이름·유형·수정 날짜·크기. Tree: 사용자 지정·이름. 자동 정렬에서도 저장된 수동 순서는 유지한다.
- Folder의 새 문서 기본 보기는 아이콘과 최대 두 줄 제목만 있는 제목 카드다. 기존 여섯 보기와 사용자의 저장된 선택을 보존한다. Card 탭·Tree를 같은 모양으로 바꾸지 않는다.
- Card와 파일 유형 필터를 공유한다. Folder는 라벨을 표시하지만 별도 라벨 필터는 적용하지 않는다.
- Folder 연결 추가는 `link note` 연결과 현재 가상 폴더 배치가 모두 성공해야 한다. 같은 Main의 다른 가상 위치와 충돌하면 전체 취소한다.
- 0.0.7 → 0.0.8의 기존 테스트용 전역 폴더 초기화는 당시 명시적으로 승인한 일회성 변경이다. 현재 문서별 폴더를 다시 초기화할 권한이 아니다.

## 6. 새 링크 파일

Card·Connections 상단 또는 Folder 빈 공간 우클릭 → `새 링크 파일 추가` → 이름 입력·실제 저장 경로 확인 → `만들고 연결`.

- 빈 Markdown을 만들고 Main의 `link note`에 연결한다. Folder에서는 현재 가상 폴더에도 배치한다.
- Obsidian 새 노트 저장 설정을 따른다. 현재 파일 폴더 설정의 기준은 Main이다. 임의의 고정 폴더를 만들지 않는다.
- 생성 후 자동으로 열지 않는다. 더블클릭으로 Sub에서 연다.
- 중복 이름 덮어쓰기 금지. 취소·잘못된 이름·Main 변경 시 생성하지 않는다.
- 실패 시 이번 작업의 연결·가상 배치를 복구하고 이번에 만든 빈 파일만 제거한다. 다른 작업으로 내용이 바뀐 파일은 보존하고 오류를 알린다.

## 7. Metadata와 재사용

- 각주 / Highlights / Tasks / Block Reference / Links의 다섯 구역. 검색·개수·접기·원문 이동을 제공한다.
- 검색어는 Main 변경 시 유지하고 재시작 시 비운다. 접힘 상태는 저장한다.
- 각주 내용 편집·저장·취소, Task 체크는 원문에 반영한다. 충돌 시 최신 원문을 덮어쓰지 않고 실패 상태를 되돌린다.
- Links는 본문·모든 속성의 HTTP/HTTPS URL만 중복 없이 표시한다. 내부 파일은 Link View에서 확인한다.
- 웹 링크마다 웹뷰어(Sub) / 기본 브라우저 선택. 웹뷰어가 꺼져 있으면 켤 위치를 안내한다.

| 끄는 항목 | Main/Sub Markdown 편집 본문 | Sub Canvas |
|---|---|---|
| Card의 파일 한 개 | 링크·임베드, Markdown은 속성을 제외한 본문 | 지원하지 않음 |
| Highlights | 텍스트·출처 포함 | 텍스트·출처 포함 카드 |
| Block Reference | 블록 링크·임베드 | 블록 내용·블록 링크 카드 |
| 각주 | 텍스트·실제 각주(참조와 정의 함께 추가) | 텍스트·각주 Markdown 카드 |
| URL Links | 주소·제목 있는 Markdown 링크 | 주소 텍스트·제목 링크 카드 |

실제 놓은 위치에 삽입한다. Canvas는 확대·이동을 반영한다. 실제 각주는 기존 번호와 겹치지 않으며 참조·정의를 한 번의 Undo로 제거할 수 있다. 기존 블록 ID를 추가·수정하지 않는다. 각주 편집 중에는 드래그하지 않는다.

읽기 모드·일반 문서·이미지·PDF·영상은 삽입 대상이 아니다. Folder/Connections/Tasks에 새 삽입 드래그를 추가하지 않는다. 기존 카드 사이 정렬은 유지한다. 취소·지원하지 않는 대상·메뉴 대기 중 원문/대상/Space 변경에서 부분 삽입을 남기지 않는다.

## 8. 완료 경계와 성능

0.0.15의 41개 테스트·빌드·Sandbox 화면·재시작·자산 일치는 기존 보고서에 기록되어 있다. 이번 문서 인계에서 다시 실행한 결과가 아니다. 0.0.15 사용자 BRAT 확인은 대기 중이며 7단계는 미시작이다.

대량 자료의 기존 측정은 각 보고서의 조건에서만 유효하다. 다른 PC의 타이핑·전체 작업 반응성 수치로 일반화하지 않는다. 별도 팝아웃 창 배치는 0.0.15 검증 범위 밖이다. Mobile·독자 편집기·실제 Vault 폴더 재구성·자동 parent/child hierarchy·전체 초기화는 제외한다.
