Canvas에 놓는 동작만
현재 버전 ↔ 변경 예정 비교

현재 0.1.8의 배치 흐름과 변경하려는 흐름을 비교합니다. 변경 예정 버전 번호는 아직 정하지 않았습니다.

이번 대상은 두 가지입니다.
① 파일을 Canvas로 직접 드래그하기
② 메뉴에서 파일·가상 폴더를 Canvas에 삽입하기

Sub 미연결 파일 차단과 Card 목록·다중 유형 필터는 사용자 확인이 끝난 항목이므로 제외합니다. 아웃라이너 내부 순서·부모 관계 변경도 포함하지 않습니다.

① 파일을 직접 드래그할 때

예: 목록에서 ‘작업 노트.md’와 ‘참고 자료.pdf’를 골라 Canvas로 끌어갑니다.

현재 버전 · 0.1.8
파일을 Canvas에 드래그하여 놓기
↓
미리보기에서 위치 지정
↓
‘이 위치에 삽입 확정’ 버튼 누르기

놓은 뒤에도 위치 지정·확정 과정이 남습니다.

변경 예정
파일을 Canvas의 원하는 위치로 드래그
↓
마우스를 놓으면 즉시 카드 배치

놓는 동작 한 번으로 배치 완료

추가 위치 클릭이나 확정 버튼이 없습니다. 파일 한 개·여러 개에 같은 방식을 적용합니다.

  • 기존 Canvas 카드와 겹치는 위치에도 놓을 수 있습니다.
  • 여러 파일은 서로 간격을 두고 함께 배치합니다. Palette 목록의 파일은 그대로 남습니다.

② 메뉴에서 파일·가상 폴더를 삽입할 때

예: 파일 여러 개 또는 ‘텍스처링’ 폴더를 선택하고 Canvas 삽입 메뉴를 누릅니다.

현재 버전 · 0.1.8
Canvas 삽입 메뉴 선택
↓
Canvas를 클릭하여 위치 지정
↓
미리보기 확인 후 별도 확정 버튼 누르기

위치 선택과 배치 확정이 분리되어 있습니다.

변경 예정
Canvas 삽입 메뉴 선택
↓
미리보기가 마우스를 따라 이동
↓
원하는 위치를 클릭하면 즉시 배치

미리 보면서 이동 → 클릭으로 완료

별도 확정 버튼을 없앱니다. 배치 전 Esc를 누르면 취소합니다.

  • 파일: 선택한 파일 카드들을 배치합니다.
  • 가상 폴더: 폴더 제목·하위 파일 카드·부모와 자식 연결선을 한 묶음으로 미리 보고 배치합니다.
  • 여러 카드 묶음이 기존 내용과 겹치면 배치를 막습니다. 다른 위치로 마우스를 옮겨 클릭합니다.

겹침 처리도 가져오는 방식에 맞게 변경

사용 동작현재 버전변경 예정
파일 직접 드래그기존 내용과 겹치면 배치 차단겹침 허용
메뉴로 카드 한 개 삽입기존 내용과 겹치면 배치 차단겹침 허용
메뉴로 여러 카드 묶음 삽입기존 내용과 겹치면 배치 차단차단 유지 · 빈 위치로 이동 후 클릭

겹침은 기존 Canvas 내용과 새 배치 사이의 겹침을 뜻합니다. 새로 넣는 여러 카드는 서로 간격을 두어 배치합니다.

2026-09-24 · 이번에 이해한 변경 내용만 담은 정적 설명용 HTML입니다. 변경 예정 동작을 구현하거나 검증했다는 보고가 아닙니다. 기존 요구사항 HTML은 이번 작업에서 수정하지 않았습니다.
